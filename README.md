# AquaGuard／水域智检——基于 YOLO 目标检测与多模态 AI 的水面漂浮物检测预警系统 

## 项目概述

AquaGuard／水域智检是一套面向 Windows 桌面环境的水面漂浮物检测预警系统。系统以 Ultralytics YOLO 单类目标检测模型为核心，通过 Electron 桌面客户端统一承载图片检测、视频检测、本机摄像头检测、多路网络点位监控、风险预警、AI 辅助复核、模型训练与评估等业务，为河流、湖泊、水库及城市景观水域提供“检测—分析—预警—处置—留痕”的完整工作链路。

系统采用本机源码双端运行模式：Electron/Vue 客户端负责图形界面和桌面能力，Flask 后端负责认证、数据管理、模型推理和异步任务。数据库、上传文件、模型、训练与评估产物、检测结果、日志及缓存均写入根目录 `runtime`，与源码目录严格分离。系统当前检测类别固定为 `0 漂浮物`，材质、污染类型和处置建议由多模态 AI 提供辅助描述，AI 结论不会覆盖 YOLO 计算出的风险等级。

### 核心创新点

1. **单类漂浮物完整检测**：使用本地 YOLO 业务模型识别画面中全部达到置信度阈值的漂浮物，返回标准化检测框、置信度、覆盖率、切图和标注结果，不再使用固定目标数量。
2. **多来源统一检测**：同一桌面客户端覆盖图片、视频、本机摄像头和 RTSP/RTSPS 网络监控点位，兼顾离线材料分析与实时值守。
3. **多路实时监控矩阵**：实时检测页最多选择 9 路已运行点位，并根据数量自动切换单画面、双画面、四宫格或九宫格；支持抽帧间隔、置信度、IoU 和 Windows 通知开关。
4. **五级风险自动判定**：系统综合目标数量与画面覆盖率，按“可忽略、轻微、中等、严重、紧急”五级规则取最高命中等级，并保存风险原因和阈值快照。
5. **实时预警闭环**：实时检测命中目标后保存 YOLO 标注证据帧与漂浮物切图，通过事件冷却规则抑制短时间重复预警，并支持详情查看、AI 复核、人工处置、批量删除和操作留痕。
6. **多模态 AI 顺序回退**：视觉模型和文本模型分组管理，可配置 Base URL、模型名、API Key、超时、重试和优先级；同类型模型失败后自动尝试下一服务。开发模拟结果始终带有明确标识。
7. **完整模型生命周期**：支持上传已训练 `.pt` 权重，也可选择数据集、基础权重、CPU/GPU 和训练参数创建任务；训练详情实时展示进度、已运行时间、预计剩余时间、指标、日志和产物，并支持停止、续训、发布及删除。
8. **可追溯模型评估**：异步计算 Precision、Recall、mAP50、mAP50-95 等指标，保存 PR 曲线、混淆矩阵、标签分布及 GT/预测对比图；历史评估可点击回看、查看详情和删除。
9. **桌面化数据可视分析**：工作台使用 ECharts 汇总近 7 日检测趋势、实时风险分布、检测来源构成和预警处置状态，并展示真实的在线点位、已发布模型和待处理预警数据。
10. **本地化安全控制**：采用 JWT、Argon2、管理员/普通用户权限、Electron Preload 白名单 IPC、一次性 WebSocket 票据、文件路径越界保护、敏感字段加密、日志脱敏和审计记录，短信与 AI 凭据不写入前端源码。

### 应用场景

- **水环境监测**：对湖泊、河流、水库和城市景观水体进行漂浮物巡查与趋势观察。
- **环保巡检取证**：保存标注画面、目标切图、检测参数、风险等级和事件时间，为人工核验提供证据。
- **水务清理调度**：依据风险等级、目标数量和 AI 辅助建议确定清理优先级，并记录处置过程。
- **园区与景区值守**：接入本机摄像头、监控摄像机或 NVR 的 RTSP 视频，实现多点位统一监控。
- **科研与教学演示**：演示数据集管理、YOLO 训练、模型评估、视觉推理和多模态 AI 协作流程。

## 技术架构

### 整体架构设计

系统由 Electron 桌面客户端、Flask 本地业务服务、YOLO 视觉算法、OpenAI-compatible 多模态服务、MediaMTX 流媒体服务和本地运行数据层组成。Electron/Vite 开发端口为 `5173`，Flask 仅监听 `127.0.0.1:5020`，REST 接口统一使用 `/api/v1` 前缀；MediaMTX 的 API、RTSP 和 HLS 分别限制在 `127.0.0.1:9997`、`127.0.0.1:8554` 和 `127.0.0.1:8888`。

```text
┌──────────────────────────────────────────────────────────────┐
│ Electron 44 桌面客户端                                       │
│ 主进程：窗口、权限、文件选择、安全令牌、Windows 通知          │
│ Preload：仅暴露经过校验的白名单 IPC                           │
│ Vue 3.5：14 个业务页面、Pinia、路由权限、ECharts、HLS 播放    │
└──────────────────────────────┬───────────────────────────────┘
                               │ REST / WebSocket
┌──────────────────────────────▼───────────────────────────────┐
│ Flask 3.1 本地服务（127.0.0.1:5020，/api/v1）                │
│ 认证权限 │ 业务接口 │ 统一响应 │ 异步任务 │ 审计与日志          │
├──────────────────┬───────────────────┬───────────────────────┤
│ Ultralytics YOLO │ OpenAI-compatible │ MediaMTX + FFmpeg     │
│ OpenCV / CLAHE   │ 文本/视觉模型回退 │ RTSP 转发与 HLS 播放  │
│ 推理、标注与切图 │ AI 辅助复核       │ 本地视频循环推流       │
└──────────────────┴───────────────────┴───────────────────────┘
                               │
┌──────────────────────────────▼───────────────────────────────┐
│ SQLite + runtime 运行目录                                    │
│ 数据库、上传、模型、训练、评估、输出、日志、缓存和密钥文件    │
└──────────────────────────────────────────────────────────────┘
```

客户端通过 REST API 完成认证、列表查询、检测提交、模型配置和处置操作，通过三类 WebSocket 通道接收异步任务快照、实时检测结果和通知事件。实时网络画面由 Electron 使用低延迟 HLS 播放，后端从 MediaMTX 本机 RTSP 出口抽帧并执行 YOLO 推理，再把检测框和预警 ID 返回客户端。训练、视频检测和模型评估使用独立 Python 工作进程执行，Windows 下采用隐藏窗口启动，避免阻塞 Flask 主服务和桌面界面。

### 技术栈详解

#### 前端技术栈

- **桌面容器**：Electron 44，负责应用窗口、摄像头权限、原生文件选择、安全令牌存储、目录打开和 Windows 桌面通知。
- **核心框架**：Vue 3.5 + TypeScript 5.9，使用 Composition API 和单文件组件构建界面。
- **UI 与图标**：Element Plus 2.11、Lucide Vue Next，形成深水蓝、湖水青、监测青绿和浅灰白的桌面视觉体系。
- **数据可视化**：ECharts 6.1，用于工作台趋势图、风险分布、检测来源和处置状态展示。
- **状态与路由**：Pinia 3.0、Vue Router 4.5，维护认证状态、权限路由、导航和业务页面状态。
- **HTTP 与流媒体**：Axios 1.12 统一处理 `/api/v1` 请求、JWT 续签与错误提示；hls.js 1.6 播放 MediaMTX 输出的低延迟 HLS。
- **工程与测试**：Vite 7、vite-plugin-electron、vue-tsc、Vitest 和 Vue Test Utils；当前以源码运行和构建校验为主，不制作安装包。
- **安全边界**：渲染进程启用 `contextIsolation` 和沙箱、禁用 Node.js 集成，IPC 请求同时校验页面来源与文件路径范围。

#### 后端技术栈

- **运行环境**：Python 3.13、Flask 3.1、Flask-SQLAlchemy 3.1、Flask-Migrate 4.1、Alembic 和 Flask-Sock。
- **数据库**：SQLite 3，采用 DELETE 日志模式；保存用户、验证码、数据集、模型、训练与评估任务、检测记录、实时会话、预警、通知、AI 配置和审计记录。
- **身份认证**：Flask-JWT-Extended、Argon2；支持密码登录、短信验证码登录、注册、短信验证后重置密码、访问令牌刷新和退出失效。
- **短信适配器**：开发环境可使用 mock 验证码；真实环境支持 HTTPS 表单或 JSON 接口、AppCode 鉴权、响应状态校验、错误分类和 60 秒发送冷却。
- **目标检测**：Ultralytics 8.4，读取已发布 YOLO 检测权重，支持 CPU 与 CUDA GPU；当前运行环境可识别 NVIDIA GPU 和 CUDA PyTorch。
- **图像与视频**：OpenCV 4.11、NumPy、Pillow、CLAHE、FFmpeg 和 FFprobe，负责媒体校验、抽帧、标注、目标切图及 H.264 转码。
- **多模态 AI**：OpenAI Python SDK 3.3，通过 OpenAI-compatible API 调用文本或视觉模型，并记录每次尝试、耗时、失败类型及是否为模拟输出。
- **流媒体服务**：MediaMTX 1.11.3，提供本机 RTSP 转发、HLS 播放和控制 API；本地视频可由 FFmpeg 循环发布为测试点位。
- **报告与运维**：python-docx 生成图片检测 Word 报告，psutil 提供运行状态，日志采用轮转与手机号、令牌、AppCode 等敏感信息脱敏。

## 项目目录结构

## 核心功能模块

1. **启动自检、用户认证与个人中心**：应用启动页检查后端、数据库、运行目录和业务模型状态。登录页支持账号密码与已绑定手机验证码两种方式，验证码发送过程提供连接提示、60 秒重发倒计时和 5 分钟有效期倒计时；开发 mock 会自动填入并明确标识。系统还支持注册、短信验证重置密码、JWT 会话续签、退出登录和个人资料维护。开发初始化管理员账号仅用于本机演示，正式环境必须修改默认密码。
2. **工作台**：汇总今日图片检测、视频任务、待处理实时预警、已发布模型、在线点位和实时会话。ECharts 展示近 7 日图片/视频/实时预警趋势、风险等级分布、检测来源构成和处置闭环率；无数据时显示明确空态。最新实时预警可直接跳转并打开预警详情。
3. **用户管理**：管理员可按关键词、角色和状态筛选用户，执行新增、编辑、启停、重置密码、单条和批量操作。系统禁止停用或删除当前管理员，并保护最后一个有效管理员；关键操作写入审计日志。
4. **数据集管理**：内置数据集以只读方式原地注册，页面可通过顶部下拉框或数据集卡片切换当前数据集。受管数据集通过 ZIP 安全导入至 `runtime/datasets`，导入时检查 Zip Slip、符号链接、解压体积、YAML 配置、图片标签配对、类别范围和数据划分；受管数据可校验和删除。
5. **模型与训练管理**：模型页面同时管理上传权重、训练任务、业务模型和版本记录。系统会检测 CPU、CUDA 可用性和 GPU 型号；创建任务时可设置数据集、基础权重、设备、Epoch、Batch、图片尺寸、优化器、耐心值和工作线程。任务详情显示阶段、进度、已运行时间、预计剩余时间、训练指标、清洗后的日志及产物，支持停止、继续训练和删除；完成权重可发布为默认业务模型。
6. **图片检测与记录**：用户选择图片后可设置置信度、IoU 和 CLAHE，系统使用已发布模型执行本地推理，展示原图/标注图对比、全部漂浮物检测框、目标数量、覆盖率、风险等级和横向切图列表。检测记录支持缩略图、详情、AI 辅助复核、批量删除和 Word 报告导出；报告包含参数、YOLO 结果、风险判断和 AI 说明。
7. **视频检测与任务记录**：上传视频后创建异步任务，通过任务通道持续更新进度。工作进程完成抽帧检测、YOLO 标注和 H.264 转码，并保存缩略图、关键帧、检测明细与切图。结果页使用单行横向滚动的关键帧列表；点击关键帧可查看标注画面、漂浮物切图、YOLO 结果并发起 AI 复核。历史列表卡片高度统一，支持详情、勾选、全选和删除。
8. **实时检测**：可选择本机检测到的摄像头设备，也可选择最多 9 路正在运行的网络点位。用户能够调整抽帧间隔、置信度和 IoU，并控制 Windows 预警通知。网络画面通过 HLS 播放，后端从本机 RTSP 出口取帧推理；检测框采用短时可视化策略，避免长期遮挡画面。每次命中返回目标、覆盖率、风险和预警 ID；主动停止或离开页面时正常关闭数据通道，不再触发异常重连提示。
9. **流媒体、预警与通知**：系统设置页展示 MediaMTX 安装状态、进程、API、RTSP/HLS 地址和运行点位数，支持启动、停止和刷新反馈。点位可来自外部 RTSP/RTSPS 或本地视频，支持创建、测试、启停和删除。预警中心只展示实时检测产生的事件，提供证据帧、漂浮物切图、YOLO 明细、AI 复核、处置历史、选择、全选和删除；导航红点与实时预警数量一致。通知抽屉独立显示系统通知和未读状态。
10. **模型评估**：管理员选择业务模型、数据集、数据划分、图片尺寸和 Batch 创建评估任务。页面实时轮询任务状态和进度，完成后显示 Precision、Recall、mAP50、mAP50-95 以及 Ultralytics 生成的 PR 曲线、混淆矩阵、标签统计和预测对比图。点击历史记录可切换上方展示内容，详情弹窗用于集中查看任务参数、指标、图表和日志。
11. **多模态 AI 模型管理**：系统设置页通过“视觉模型/文本模型”切换分别展示两类服务，可新增、编辑、测试、启停、排序和删除 OpenAI-compatible 模型。视觉复核过程中用阶段文字、进度条和已等待时间反馈分析状态；结果按现场判断、材料线索、风险结论、证据和处置建议结构化展示。系统过滤模型输出中的内部思考标签，真实与模拟结果严格区分，YOLO 风险等级始终保持独立。
12. **系统设置、安全与运行状态**：管理员可查看客户端、后端、SQLite、模型、GPU、磁盘、MediaMTX 和运行目录状态，管理检测默认值、五级风险阈值、存储策略、日志、短信服务和多模态 AI。REST 响应统一为 `{code, message, data, requestId, timestamp}`，分页统一为 `{items, page, pageSize, total}`；文件下载和 Electron 目录打开都执行 runtime 边界检查。API Key 加密存储在本地数据库中，短信 AppCode 等启动凭据仅从 `.env` 或系统环境变量读取，日志会脱敏手机号、令牌和密钥信息。
